Serving behavior

Which recipes were fastest for training, prompts, and generation?

When a model answers a prompt, it does two jobs. First, it reads the entire prompt; this is called prefill. It then produces the answer one token at a time; this is called decode.

During decode, the model needs information from earlier tokens. A key-value cache (KV cache) keeps the key and value data already created for those tokens, so the model does not create that data again for every new token.

Training is different. The model makes predictions, checks its mistakes, and updates what it has learned.

Reading a prompt, generating an answer, and training are different kinds of work. A recipe may be fast at one and slow at another, so the buttons compare them separately.
