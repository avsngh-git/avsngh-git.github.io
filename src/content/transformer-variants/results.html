How to read this chapter

Different questions produce different leaders

“Best model” is incomplete without naming the resource. Prediction quality, training time, stored parameters, KV-cached generation, prompt processing, and behavior beyond the training length are different outcomes.

The charts answer one question at a time. An unsupported capability is kept distinct from a measured zero, and the controls state which measure changes when selected.

Which recipes remained stable beyond 1K tokens?

Each point scores the same final 256 targets while the visible prefix grows. Perplexity therefore asks whether extra context and unseen position ranges help or destabilize prediction; prefill throughput asks how efficiently the operator processes that longer prompt. Tail perplexity uses a logarithmic scale because the degradation spans more than an order of magnitude.

Distant-information access

Did stable prediction mean the model retrieved a distant fact?

Paired-tail perplexity measures whether the same final targets remain calibrated as the prefix grows. The zero-shot passkey and needle probes ask a stricter question: can the model place probability on a specific answer introduced at a controlled distance? No task-specific fine-tuning is used. Exact top-1/top-5 accuracy is shown alongside answer-token probability and negative log-likelihood so floor effects remain visible rather than being hidden.

Serving behavior

Which recipes were fastest for training, prompts, and generation?

A key-value cache (KV cache) saves attention information from earlier tokens so it does not need to be recomputed after every generated token. Prefill processes the input prompt; decode generates later tokens one at a time, usually by reusing that cache.

Training adds backward passes and optimizer work. These workloads exercise different kernels and memory paths, so one throughput number cannot describe all of them.
