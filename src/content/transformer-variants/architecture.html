How the recipes relate

Three parts of the Transformer are being changed

The recipe names become easier to compare when they are mapped to three design questions: how position is represented, how tokens exchange information, and how much feed-forward capacity is available to each token.

01

Position

Learned vectors, RoPE, and ALiBI give the model different rules for representing token order and distance.

02

Token interaction

Full, grouped-query, sliding-window, hybrid, and linear attention create different information paths and memory costs.

03

Per-token capacity

Dense feed-forward networks use the same parameters for every token. MoE routes different tokens through selected experts.
