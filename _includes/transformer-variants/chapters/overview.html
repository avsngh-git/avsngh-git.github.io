The research question

When a Transformer is called “efficient,” which resource actually improved?

A Transformer variant may change positional information, the connectivity of attention, the number of key/value heads, the feed-forward network, or the amount of capacity activated for each token. Those interventions target different bottlenecks. A method can reduce theoretical attention work while running slowly on a real GPU; improve next-token loss while increasing stored parameters; or survive a 4K input only because it never looks beyond a local 256-token window.

I built this project to make those distinctions measurable. Ten decoder-only recipes share the same GPT-2 tokenizer, FineWeb-Edu token stream, 1,024-token training length, 499,974,144-token budget, optimizer schedule, validation windows, and primary hardware. Each main recipe was trained from five random seeds. The evaluation then asks separate questions about quality at fixed data, progress at fixed wall-clock time, estimated compute, context extrapolation, prompt prefill, generation, representation geometry, and attention structure.

Executive summary

Three findings define the project

These are not three independent leaderboard wins. Each result becomes useful only when the mechanism, the measured evidence, and the boundary of the claim are stated together.

01

MoE delivered the best fixed-data loss, but conditional capacity was not free

Full MoE replaced every dense SwiGLU block with eight experts and routed each token to the top two. It reached 3.6862 validation loss (95% CI 3.6753–3.6971), the best result at the common token budget. The paired five-seed difference from Modern was −0.1236 loss (95% CI −0.1381 to −0.1092). Active parameters were deliberately matched: 51.46M for MoE versus 51.43M for Modern. MoE still stored 103.37M parameters and trained at 31.2K tokens/s, versus Modern's 69.7K.

What that means: sparse activation expanded the conditional function family enough to improve prediction at nearly equal per-token parameter activation. The extra inactive experts and dispatch path made “more accurate” very different from “fewer stored parameters” or “faster training.”

02

The positional rule dominated long-context behavior

ALiBI finished with a weaker 1K loss than Modern and every MoE recipe, but produced the best 4K tail perplexity: 74.35 ± 1.14. Modern rose from 49.96 at 1K to 410.08 at 4K; the MoE family rose from 43.70–45.99 to 404.51–432.04. Extra conditional capacity did not repair a positional distribution shift shared by the global RoPE-based family.

What that means: the learned task at 1K and the rule used to represent distance beyond 1K are separate capabilities. ALiBI preserved a distance rule that remained defined at 4K. SWA was similarly stable for a different reason: it kept solving the same local 256-token problem.

03

Better asymptotic complexity did not guarantee better realized throughput

Causal linear attention avoids materializing the quadratic softmax matrix by carrying prefix statistics. In this implementation, however, training reached only 53.4K tokens/s at 1K sequences, while SWA reached 80.2K and GQA 80.2K. Its fixed-data loss was 4.0782—worse than Modern's 3.8099 despite processing the same 499,974,144 tokens. At serving time it reached 178.2 cached generation tokens/s versus Vanilla's 512.8, and only 34.3K tokens/s for 4K prefill versus SWA's 204.9K.

What that means: Big-O behavior describes growth in a limit; it does not include kernel fusion, serial recurrence, memory traffic, or GPU occupancy at the sequence lengths and hardware tested here. The result evaluates this causal ELU+1 recurrence—not all linear-attention research.

Central claim

This is an experimental platform rather than ten isolated model classes. Its contribution is the connection between architectural intent, controlled training, uncertainty-aware evaluation, measured systems behavior, internal diagnostics, and reproducible publication. The most important outcome is therefore not a single winning recipe; it is a defensible map from mechanism to trade-off.
