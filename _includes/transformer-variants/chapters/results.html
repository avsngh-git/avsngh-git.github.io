How to read this chapter

The ranking changes when the resource changes

“Best model” is under-specified. Full MoE is best after a fixed number of training tokens. Vanilla is fastest in the measured short-generation path. SWA leads 4K prompt prefill. ALiBI is most robust on the 4K tail-quality test. Those statements can all be true because they optimize different quantities.

The figures below deliberately preserve that multidimensional result. Every chart is displayed at full width; the learning-curve views occupy the same figure one at a time so labels and seed traces remain legible. Interactive controls are marked in blue and announce exactly what changes when selected.

Training efficiency

The same learning histories, viewed against three budgets

Re-plotting the same checkpoints changes the denominator, not the underlying observations. Fixed tokens emphasizes how much a recipe learns from data; wall-clock includes the implementation's real speed; estimated FLOPs emphasizes modeled arithmetic. A result that survives all three views is stronger than a result visible on only one convenient axis.

Long-context extrapolation

Good 1K quality did not predict good 4K behavior

Each point scores the same final 256 targets while the visible prefix grows. Perplexity therefore asks whether extra context and unseen position ranges help or destabilize prediction; prefill throughput asks how efficiently the operator processes that longer prompt. Tail perplexity uses a logarithmic scale because the degradation spans more than an order of magnitude.

Serving behavior

Generation and prefill exercise different hardware paths

Autoregressive generation advances one token at a time and benefits strongly from reusable key/value state. Prefill processes all prompt tokens in parallel and exposes the attention operator's behavior at long sequence lengths. A single throughput number cannot describe both workloads.
