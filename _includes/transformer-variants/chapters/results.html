How to read this chapter

The ranking changes when the resource changes

“Best model” is under-specified. Fixed-data quality, cached decode, uncached generation, long-prompt prefill, stored parameters, active parameters, and extrapolation stability are different endpoints. The same recipe need not lead all of them, and an unsupported capability is kept distinct from a measured zero.

The figures below deliberately preserve that multidimensional result. Every chart is displayed at full width; the learning-curve views occupy the same figure one at a time so labels and seed traces remain legible. Interactive controls are marked in blue and announce exactly what changes when selected.

Training efficiency

The same learning histories, viewed against three budgets

Re-plotting the same checkpoints changes the denominator, not the underlying observations. Fixed tokens emphasizes how much a recipe learns from data; wall-clock includes the implementation's real speed; estimated FLOPs emphasizes modeled arithmetic. A result that survives all three views is stronger than a result visible on only one convenient axis.

Long-context extrapolation

Good 1K quality did not predict good 4K behavior

Each point scores the same final 256 targets while the visible prefix grows. Perplexity therefore asks whether extra context and unseen position ranges help or destabilize prediction; prefill throughput asks how efficiently the operator processes that longer prompt. Tail perplexity uses a logarithmic scale because the degradation spans more than an order of magnitude.

Distant-information access

Stable perplexity is not proof that a model retrieved a distant fact

Paired-tail perplexity measures whether the same final targets remain calibrated as the prefix grows. The zero-shot passkey and needle probes ask a stricter question: can the model place probability on a specific answer introduced at a controlled distance? No task-specific fine-tuning is used. Exact top-1/top-5 accuracy is shown alongside answer-token probability and negative log-likelihood so floor effects remain visible rather than being hidden.

Serving behavior

Training, generation, decode, and prefill exercise different hardware paths

Training combines forward, backward, optimizer, and gradient-accumulation work. Autoregressive generation advances one token at a time and benefits strongly from reusable key/value state; steady-state decode removes prompt setup from that timing. Prefill processes prompt tokens in parallel and exposes the attention operator at long sequence lengths. One throughput number cannot describe all four workloads.
