Comparison framework

One recipe name can hide several architectural decisions

The ten recipes are easiest to understand as interventions along three axes: how position is represented, which tokens and heads can exchange information, and how per-token nonlinear capacity is allocated. Vanilla and Modern change all three component families at once; ALiBI, GQA, SWA, linear attention, and the MoE recipes then modify selected parts of the Modern backbone.

This matters for causal interpretation. If MoE outperforms Modern, the attention operator and RoPE are unchanged—the intervention is feed-forward capacity. If ALiBI extrapolates better, its RMSNorm and SwiGLU remain comparable to Modern—the key intervention is the positional rule inside attention. The comparisons below make that experimental structure explicit.

Axis 1 · Position

Three ways to tell attention where a token is

Causal masking controls direction; positional mechanisms supply distance. The experiment tests one learned absolute scheme and two relative schemes, RoPE and ALiBI.

Used by Vanilla

Learned absolute positions

What is used

A trainable vector is assigned to each index from 0 through 1,023 and added to the token embedding before the first block. Position 17 and position 817 therefore have separate learned parameters. Attention remains ordinary causal multi-head softmax attention.

Expected effect

The lookup table can fit position-specific regularities inside the training range. Its hard limit is equally clear: position 1,024 has no trained embedding, so extrapolation requires inventing or resizing parameters rather than applying an already defined rule.

Observed in this experiment

Vanilla was a strong systems baseline—3.6984 fixed-data loss and the best short-generation throughput at 454.55 tokens/s. The evaluator correctly marked 2K and 4K quality as unsupported, a direct consequence of the finite learned position table.

Used by 8 RoPE-based recipes

Rotary position embeddings (RoPE)

What is used

RoPE rotates query and key coordinates by position-dependent angles before their dot product. Relative phase expresses distance without adding a learned position vector. Modern, GQA, both SWA recipes, causal linear attention, and all three MoE recipes use RoPE.

Expected effect

Relative phase should provide a cleaner inductive bias than unrelated absolute lookup vectors and removes learned position parameters. Angles far beyond the 1K training range can still create unfamiliar phase relationships, so unscaled RoPE has an extrapolation path but not a stability guarantee.

Observed in this experiment

RoPE-based global recipes were excellent at 1K: MoE reached 31.91 tail perplexity and Modern 39.80. At 4K, Modern rose to 553.94 and the MoE family to 488.85–526.63. More capacity did not remove the shared length shift.

Used by ALiBI

Attention with Linear Biases (ALiBI)

What is used

ALiBI leaves queries and keys unrotated and subtracts a head-specific linear penalty as key distance grows. Steep-slope heads prefer local evidence; shallow-slope heads preserve broader context. No position embedding is added to the residual stream.

Expected effect

The same monotonic distance rule is defined at 1K, 2K, and 4K, avoiding new positional parameters or phases. The cost is an explicit recency prior: distant evidence is penalized even when semantically important.

Observed in this experiment

ALiBI had weaker in-range quality than Modern—3.9025 versus 3.6176 loss—but the best 4K tail perplexity at 58.74 ± 1.10, only 1.047× its 1K value. A stronger distance prior traded some 1K fit for markedly better extrapolation.

Position-level conclusion

Absolute embeddings had no declared route beyond 1K. RoPE had a route but global-attention recipes did not remain calibrated at 4K. ALiBI kept the distance function structurally unchanged and extrapolated best. SWA also used RoPE but stayed stable because each query still saw only 256 recent positions—local transfer, not general long-range retrieval.

Axis 2 · Token interaction

Five attention topologies, five different bottlenecks

All variants are causal. What changes is whether every earlier key is represented, whether key/value heads are shared, whether distance is truncated, and whether a pairwise softmax matrix exists at all.

Vanilla · Modern · ALiBI · MoE family

Full multi-head attention

Mechanism. Every query head can score every earlier key and keeps its own query, key, and value projections.

Expected effect. Maximum token-level addressability and mature kernels, with quadratic score interactions as context grows.

Observed in this experiment. Full attention supported the best in-range quality through MoE and strong generation through Vanilla, but global RoPE members degraded at 4K. Connectivity does not guarantee positional calibration.

GQA · 8 query heads / 2 KV heads

Grouped-query attention

Mechanism. Query heads remain distinct, while groups of four queries share one key and one value head.

Expected effect. Cheaper KV parameters, memory, and bandwidth with a possible quality penalty from shared keys and values.

Observed in this experiment. GQA reduced parameters from 51.4M to 48.3M and reached 239.6K 4K-prefill tokens/s, but loss worsened to 3.9565. Its cache route remained unsupported, so this experiment does not claim the intended decode-memory benefit.

SWA · 256-token window

Sliding-window attention

Mechanism. Each layer restricts a query to itself and the preceding 255 tokens. Information can travel farther through depth, but no direct edge reaches an arbitrarily old token.

Expected effect. Work proportional to sequence length times a fixed window, a strong locality prior, and reduced direct long-range retrieval.

Observed in this experiment. SWA led 4K prefill at 253.4K tokens/s and stayed flat from 1K to 4K perplexity, but had weaker 1K quality than Modern. The flat curve means the local task transferred cleanly.

SWA interleaved · alternating full/local

Interleaved global and local attention

Mechanism. Even layers use full causal attention and odd layers use the 256-token window.

Expected effect. Recover long-range paths and in-range quality without paying for full attention in every block.

Observed in this experiment. Loss improved slightly over pure SWA, 3.9333 versus 3.9427, while 4K perplexity rose to 84.86. Global RoPE layers recovered connectivity and reintroduced length sensitivity.

Linear · ELU+1 prefix recurrence

Causal linear attention

Mechanism. A feature map factorizes attention into recurrent prefix statistics; history becomes a fixed-size state rather than an explicit softmax matrix.

Expected effect. Linear sequence scaling and bounded state, traded against exact token addressability and feature-map approximation.

Observed in this experiment. The corrected model trained stably but reached only 34.7K 4K-prefill tokens/s and 1,311.78 tail perplexity. Serial unfused work lost to optimized softmax kernels in this regime.

Axis 3 · Per-token transformation

Dense FFNs, gated FFNs, and sparse conditional capacity

Vanilla

Standard dense FFN

Mechanism. Two linear maps with ReLU expand each token to four times model width and project it back.

Expected effect. Predictable dense kernels and a transparent baseline, with less selective gating.

Observed in this experiment. Vanilla did not win quality, but conventional operations and its supported cache path produced the best short-generation rate.

All non-Vanilla recipes

SwiGLU dense FFN

Mechanism. A SiLU-activated projection gates a second projection elementwise before the output map.

Expected effect. More selective nonlinear behavior while preserving dense batch-friendly execution.

Observed in this experiment. Modern improved loss over Vanilla, although RoPE, RMSNorm, and SDPA changed simultaneously; SwiGLU is not isolated by that pair alone.

MoE · interleaved · deep

Mixture of experts

Mechanism. Eight SwiGLU experts are stored at an MoE layer; a router selects the top two. Full MoE uses every block, interleaved MoE the odd blocks, and deep MoE the second half.

Expected effect. Expand conditional capacity without executing every stored parameter, while risking imbalance, irregular kernels, and memory cost.

Observed in this experiment. All placements beat Modern on fixed-data loss; full MoE was best. Partial placement recovered much of the gain with fewer parameters, but remained slow and did not repair RoPE extrapolation.
